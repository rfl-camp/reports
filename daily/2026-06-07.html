内存管理

为 Rust 添加 per-task 内存分配作用域抽象（v2）

为 Rust 添加 per-task 内存分配作用域抽象（v2）

Andreas Hindborg 提交、Gary Guo 审查了一组补丁，为 Rust 内核代码添加了"per-task memalloc scope"（按任务的内存分配作用域）抽象。这是什么意思呢？在 Linux 内核中，不同的代码路径在分配内存时有不同的"规矩"——比如在处理内存回收的代码里，你分配内存时不能触发更多的内存回收（否则就死循环了）。这种"规矩"是通过给每个任务（进程/线程）设置分配标志来实现的。这个补丁把这套机制用 Rust 的类型系统包装起来，让 Rust 驱动代码也能安全地控制内存分配行为，避免在关键路径上出现意外的内存分配死锁。

I2C 设备驱动

I2C 设备驱动

修复 I2cAdapter 引用计数重复增加（v3）

修复 I2cAdapter 引用计数重复增加（v3）

Igor Korotin 提交了一个修复补丁，解决了 Rust I2C 适配器驱动中引用计数被重复增加的 bug。I2C 是一种简单的硬件通信协议，你的笔记本里的温度传感器、触摸板控制器等很多小设备都是通过 I2C 连接的。在内核中，每个设备对象都有一个"引用计数"——记录有多少地方在使用它，当计数归零时才能安全释放。如果引用计数被多加了一次，对象就永远不会被释放，造成内存泄漏。这个补丁修复了 Rust I2C 绑定中的这个逻辑错误，已经是第三版，说明之前的修复方案有过改进。
